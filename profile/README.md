# 🌌 Stellaris DLC Unlocker: Automatic DLC Unlocker Tool

**Stellaris DLC Unlocker** is a utility designed to automatically unlock and activate downloadable content (DLC) for **Stellaris** on Steam.  
This tool streamlines DLC management for supported expansions, content packs, and additional modules.

# 🧰 Requirements

Before using Stellaris DLC Manager, ensure you have:

* A legitimate copy of **Stellaris**
* Steam or Paradox Launcher installed
* Active internet connection for license verification
* .NET 7 Runtime (or newer)
* Stellaris fully installed and updated

# ⚡ Installation & Setup Guide

## 1️⃣ Download the Tool

Download the latest release from the GitHub Releases page.

## 2️⃣ Extract Files

Unzip the archive into a folder of your choice.

## 3️⃣ Run the Application

Launch the executable (Administrator optional depending on system permissions).

## 4️⃣ Select Game Directory

Point the tool to your Stellaris installation folder.

## 5️⃣ Scan DLCs

Click **Scan DLCs** to detect installed and owned expansions.

## 6️⃣ Launch Game

Start Stellaris directly using the built-in launcher shortcut.
